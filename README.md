## About Me

I'm a Computer Engineering student at **Madhuben & Bhanubhai Patel Institute of Technology (MBIT), CVM University**, interested in building intelligent applications that solve practical problems.

My work brings together machine learning, natural language processing, backend development, and AI-powered automation. I enjoy taking an idea from data processing and model development to a functional application.

- Building AI-powered automation workflows and Python applications.
- Developing machine learning and NLP projects.
- Exploring LLMs, Retrieval-Augmented Generation (RAG), and Agentic AI.
- Published institutional research on the risks of AI in healthcare.
- Contributing to open source and collaborative software projects.

**Current direction:** Practical AI engineering, intelligent automation, and reliable data-driven applications.
