**Tech Stack:** Python, TensorFlow, Keras, OpenCV, NumPy

* Performance evaluation using accuracy metrics and confusion matrices

### Fake News Detection

Machine Learning application that classifies news articles as real or fake using Natural Language Processing.

**Tech Stack:** Python, Pandas, NLTK, Scikit-learn, Flask

**Highlights**

* TF-IDF vectorization

* Real-time prediction through Flask web application
